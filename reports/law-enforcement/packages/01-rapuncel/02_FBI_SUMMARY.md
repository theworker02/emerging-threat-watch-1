# Rapuncel — Summary

**Package:** `ETW-RAP-IC3` · **Status:** FILED_IC3 · **Cutoff:** 2026-09-19

## Overview

Defensive threat-intelligence package concerning Rapuncel, a Windows information-stealer distribution operation publicly documented by LastPass TIME and Delphos (2026-09-17). Researchers described fraudulent SEO-oriented GitHub repositories and GitHub Pages used to distribute the stealer, with a chain using legitimate Microsoft `vsdbg.exe` for DLL sideloading and a malicious `vsdbg.dll` loader assessed (high confidence by those researchers) as generated by Cruciferra/PUROSANGUE or a close derivative. **Cruciferra is crypter/delivery tooling context only — not equated with Rapuncel authorship.** Published hashes, domains, and IPs are retained as PRIMARY-SOURCE. Passive follow-up recorded an additional GitHub Pages lure (`massimolongqdoj.github.io` → `albinofennel.com`), CT chronology, and NXDOMAIN for `albinofennel.com` as of 2026-09-19 (OBSERVED_PASSIVE facts — not ownership).
