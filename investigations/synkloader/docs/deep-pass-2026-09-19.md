## New technical facts (Expel primary)

### Teams phishing delivery

- External `*.onmicrosoft.com` tenant, display name “IT Service Desk”
- MSI: `https://filereserve.blob.core.windows.net/vgnghuyk/331/331.msi` (`PowershellCleaner`)
- SHA-256 `331.msi` = `151d2a7f52f047638ca8ad80c859c6bfe04d7510fb10933817fa0e3ba5d07a11`

### Loader chain

- `%LocalAppData%\PowershellCleaner\script\` → `cleaner.ps1` + `archive6.zip`
- Nested PowerShell: hex char-join → AES-CBC → `ScriptBlock::Create` (in-memory)
- Extract to `%AppData%\<16-char>\fl\ang\` with bundled Python; launch `pythonw.exe ss.py`
- Victim ID = 16-character random install directory

### C2 crypto / domains

- Domains: `neversoftmain.net`, `rootfarmapp.net`, `tripinupdate.net`
- URL shape: `https://<domain>/<token>/<victim_id>/`
- Beacon interval 90–120s; JSON ping with `local_id` / `timestamp`
- Modified ChaCha20 sigma: `mlswgtppayebtezk` / `lwifnrfiosmfrubf`; key = victim ID

### Fake lock-screen (PhishLocker)

- DLL GUI mimics Windows 11 lock screen
- `GetUserName` + wallpaper from `C:\Windows\Web\Screen`
- Fullscreen borderless app; **no** Windows Auth validation
- Alt+Tab visible (malware re-focuses); any password dismisses UI
- Expel: no prior local-malware references found before 2026-08-18 investigation
